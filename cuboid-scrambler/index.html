Cuboid scramble generator

Settings

Slice moves
Scramble using slice moves (eg. 3R), turning only that one layer. When off, scramble using wide moves, meaning every layer from the outside to that layer is turned. This changes which pieces you turn, not just how the move is written, but both settings should reach roughly equally random states.
Efficient mode
On the axis that bandages next phase, only scramble the layers whose independence is about to be lost. Deeper layers survive the reduction and get mixed in later phases, so no scrambling is wasted on pieces that will be rearranged anyway.
Outside-numbered layers
Number layers by their distance from the outside of the puzzle's full size, fixed for the whole scramble. By default layers are renumbered every phase to count only the ones currently movable, so the same name can mean a different layer later on.
Constant-cube view
Draw the puzzle as a fixed cube, with the shorter axes' outer layers drawn thicker, so it never appears to change shape. Needs all-even or all-odd dimensions. Affects the diagrams only — the scramble itself and the functionality is unchanged.
Show shapeshifted state for hovered moves
Hovering a move shows the coloured puzzle as it actually looks at that point in the scramble, with the layer about to turn highlighted. When off, hovering shows a plain schematic of the reduced cuboid instead.
