Tiling

Asking once marks what to look at; asking again names the reasoning.

Click to uncover. Right-click to plant a flag. Clicking a number that already has its full quota of flags beside it uncovers everything else it touches.

Difficulty

Hidden numbers

With these on, some cells never show their count when uncovered — they only prove themselves safe, and where the boxes carry numbers some of those are kept back too. Every board is still one that can be finished without guessing.

Strict

With this on, uncovering a cell that the board does not yet rule out as a mine finds a mine there. Only cells you can actually prove safe are safe, so guessing never pays. Every board can still be finished, and boards played this way set no best time.

Show neighbours

With this on, resting the pointer on a number lights the cells it counts — which a tiling of pentagons does not make obvious by looking.

Relaxed

With this on, uncovering a mine shows it for a moment and then covers it again, and the game goes on. Boards finished this way set no best time.
